## Context the next agent should know

- Valid cache configurations are generated by enumerating small didactic
  ranges for address bits, block bits, index bits, and associativity bits,
  filtering explicit user constraints, then selecting one candidate with a
  seedable PRNG.
- `--ways` is the actual associativity and must be a positive power of two;
  internally it is converted to `cacheways = log2(ways)` to match the old
  `vz-cache` model.
